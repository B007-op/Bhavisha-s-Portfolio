# Bhavisha Chafekar Portfolio

A responsive GitHub Pages portfolio for business analytics, data analytics, consulting, and research work.

## Publish on GitHub Pages

1. Upload all files and folders in this package to the repository root.
2. Open **Settings > Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.

The `index.html` file must remain in the repository root.
