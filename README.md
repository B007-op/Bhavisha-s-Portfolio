# Bhavisha Chafekar — Portfolio Website

A responsive, single-page portfolio designed for analytics consulting, business analysis, data analysis, strategy, decision support, and AI-enabled operations roles.

## Included

- Executive-style hero with quantified impact
- Experience timeline across Medtronic, Carlson Analytics Lab, Technocrat Solutions, and SPJIMR
- Nine filterable project case studies
- Professional project photography from 4MATIV, Barclays, and the AGI Hackathon
- Case-study and photo lightboxes
- Skills, education, publications, and patent sections
- LinkedIn, GitHub, email, and downloadable project portfolio links
- Responsive mobile layout and reduced-motion support

## Preview locally

Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public repository such as `bhavisha-portfolio`.
2. Upload **all files and folders inside this package** to the repository root.
3. Open **Settings → Pages** in the GitHub repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Add the GitHub Pages URL to the repository’s **About → Website** field.

## Main files

- `index.html` — content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — filtering, animations, counters, case studies, photo lightbox, and copy-email behavior
- `assets/` — social card, favicon, project portfolio PDF, and optimized photographs
