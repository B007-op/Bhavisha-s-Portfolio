# Bhavisha Chafekar Portfolio, August 3 Refresh

## Upload these items to the repository root

- `index.html`
- `bhavisha-portfolio-v3.css`
- `bhavisha-portfolio-v3.js`
- `.nojekyll`
- `README.md`

Delete the older `styles.css` and `script.js` files after uploading this version. The new filenames and version tags help prevent the browser from displaying a cached copy.

## GitHub Pages settings

Use `main` and `/ (root)` under Settings, Pages.

After deployment, open the site in an Incognito window or press `Ctrl + Shift + R` once.
