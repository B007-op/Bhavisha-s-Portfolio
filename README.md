# Bhavisha Chafekar Portfolio

A responsive GitHub Pages portfolio for business analytics, data analytics, consulting, projects, wins, and research.

## Publish on GitHub Pages

1. Upload all files and folders in this directory to the root of the GitHub repository.
2. Open **Settings**, then **Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save and wait for the Pages deployment to finish.

## Main files

- `index.html`: website content
- `styles.css`: visual design and responsive layout
- `script.js`: navigation, carousel, filters, modals, and interactions
- `assets/`: images, project portfolio PDF, favicon, and social preview
