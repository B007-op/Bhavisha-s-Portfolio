# Bhavisha's Portfolio

A personal portfolio website for Bhavisha Chafekar, focused on business analytics, data analysis, consulting, competitions, and research.

## Publish with GitHub Pages

1. Upload all files in this folder to the root of the GitHub repository.
2. Open **Settings**.
3. Open **Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for GitHub Pages to publish the site.
